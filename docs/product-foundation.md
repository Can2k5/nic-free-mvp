📄 Ayo — Product Foundation (Tag 1)
1. Overview
Ayo is a nicotine-free companion designed to help users quit and stay quit.
The app focuses on:
	•	making recovery visible
	•	reinforcing consistent progress
	•	supporting users through setbacks
Ayo is not just a tracking tool. It is a system that helps users commit to quitting and follow through.

2. Core Value Proposition
Ayo helps users:
	•	make a clear decision to quit
	•	see real progress over time
	•	stay consistent even after slips
The product is built around the idea:
👉 “Push when strong. Catch when weak.”

3. Entry Point
The primary user mindset is:
👉 “I want to quit.”
Ayo is designed for the moment of decision — not just maintenance or crisis.

4. Core Pillars
1. Recovery & Progress (Primary)
Users can see how their body and behavior improve over time.
Focus:
	•	recovery feedback
	•	visible progress
	•	forward movement

2. Daily Accountability
Simple daily interactions keep users consistent.
Focus:
	•	check-ins
	•	continuity
	•	habit formation

3. Rescue (Secondary)
Support tools are available when needed, but are not the main focus.
Important:
	•	not dominant in UI
	•	only activated when relevant

5. UX Philosophy
Ayo follows a principle of:
👉 Calm urgency
Meaning:
	•	emotionally engaging
	•	serious, not playful
	•	slightly pushy, but not aggressive
	•	never punishing after setbacks

6. Emotional Design
The app creates two core emotional states:
During progress:
	•	motivation
	•	discipline
	•	pride
After setbacks:
	•	understanding
	•	safety
	•	continuation

7. Home Screen Structure
The home screen follows a clear hierarchy:
Primary:
	•	recovery / body progress
Secondary:
	•	streak (days nicotine-free)
This ensures stability even after slips.

8. Monetization Strategy
Ayo uses a Hybrid Monetization Model:
Flow:
	1	User completes onboarding
	2	User has first meaningful interaction
	3	User experiences value
👉 Then:
Hard Lock
The app is locked after initial use.
To continue, users must:
👉 Start a 3-day reset (trial)

9. Paywall Philosophy
The paywall is not feature-driven.
It is framed as:
👉 continuation of a decision
Core message:
	•	“You’ve already started”
	•	“Don’t break this now”
	•	“Finish what you started”

10. Pricing
	•	Monthly: 7.99€
	•	Yearly: 39.99€ (Best Value)
Positioning:
	•	mid-tier premium
	•	accessible but serious

11. Product Positioning
Ayo is not:
	•	a simple habit tracker
	•	a motivation app
	•	a rescue-only tool
Ayo is:
👉 a system for quitting nicotine and staying consistent

12. Key Product Principle
👉 Progress over pressure
The user should always feel:
	•	forward movement
	•	support
	•	continuity
Even after failure.
