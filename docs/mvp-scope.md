# Ayo MVP Scope

## Goal
Build a very small mobile MVP for a nicotine quitting app that helps users survive cravings and see simple progress.

## In Scope

### 1. Home Screen
- show nicotine-free days
- show money saved
- show cravings defeated
- show a primary button: "I have a craving"

### 2. Craving Screen
- calming headline
- short supportive text
- 60 second timer
- button: "I made it"
- after finishing, increase cravings defeated by 1

### 3. Progress Screen
- show current streak
- show total cravings defeated
- show simple milestones

## Data
- local mock data only
- no backend
- no login
- no cloud sync

## Design
- minimal
- modern
- clean
- calm
- iOS-friendly
- card-based layout
- simple bottom tab navigation

## Out of Scope
- AI coach
- community
- push notifications
- payments
- subscriptions
- detailed health analytics
- settings
- onboarding
